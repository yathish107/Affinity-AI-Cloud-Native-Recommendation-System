# Start Here

1. Install/open Docker Desktop.
2. Extract the project ZIP.
3. Open PowerShell in the project folder.
4. Run `docker compose up --build`.
5. Open `http://localhost:8080`.
6. Enter `student1` and interact with products.
7. Click **Get Recommendations**.
8. For your presentation, explain the flow: Frontend -> FastAPI -> Event Broker -> Event Store/ML -> Recommendations.
